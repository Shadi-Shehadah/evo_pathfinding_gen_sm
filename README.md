This thesis explores a novel method for generative design of sheet metal brackets. The application of generative design within sheet metal manufacturing has received limited academic attention. Furthermore, existing methodologies fail to simultaneously optimize for both manufacturing cost and structural integrity. The method uses a genetic algorithm for the optimization. The candidate solutions are represented by a hybrid genotype-phenotype encoding that allows for freely exploring the search space while still adhering to sheet metal manufacturing considerations. The 2D profile of the sheet metal part is generated via a pathfinding algorithm which is influenced by genetic data from the evolution. This method is shown to be effective at generating valid 2D profiles of brackets in a variety of situations.
